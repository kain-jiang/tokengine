## 页脚钉死修复 + 回到顶部（第 3 轮反馈）

- **根因**：`PageLayout.jsx` 中 `Layout.Footer` 位于滚动容器 `Content` 之外，外层是 100vh flex 列布局，footer 被钉在视口底部；首页长内容在 Content 内滚动，所以 footer 看起来「固定不动」。
- **修复**：非控制台路由（`footerInFlow = !isConsoleRoute`）把 Footer 移入 Content 内，Content 加 `display:flex; flexDirection:column`，App 外包 `flex:1 0 auto` 的 div——长页面 footer 跟随瀑布流末尾，短页面仍吸底。控制台页面保持原样。
- **回到顶部**：`Home/index.jsx` 接入 Semi `BackTop`（semi-ui 2.97 自带），`visibilityHeight=400`，桌面端 target 为 `.semi-layout-content`，移动端为 window。
- **构建验证**：`vite build` 18362 模块 transform 全过；写 dist 时被 WorkBuddy 沙箱 safe-delete 守卫拦截（126 文件超阈值）——环境限制，用户本地构建不受影响。沙箱内想完整构建可用 `--outDir` 指向临时目录规避。

## Footer 压扁（第 4 轮反馈）

- **根因**：footer_html 配置为空 → 走 `Footer.jsx` 的 customFooter 分支，该分支写死 `py-16`（上下各 64px），非演示站只有一行版权文字，显得空旷。另：`bg-dark-blue` 类在项目里不存在，所以背景是透明的（白底），文字靠 Semi 默认色渲染。
- **修复**：`Footer.jsx` customFooter 改为条件 padding——演示站（有链接列）保持 `py-16`，非演示站 `py-4`；两个分支都加 `border-t border-semi-color-border` 细分隔线。
- **再调**：py-4（16px）用户嫌太窄 → 最终定为 `py-8`（32px），两个分支统一。
- **部署链路（重要）**：后端 `main.go` 用 `go:embed web/dist` 把前端嵌进 exe——前端任何改动（含 public 下的 silicon-landing.html）都必须 `bun run build` → 重新 `go build` → 重启 exe 才生效。
- 后端 localhost:3000 在会话中停止响应（用户可能在重启）。
