# 2026-08-02

## 新建硅基流动风格首页 silicon-landing.html

- 产出：`web/public/silicon-landing.html`，复刻 siliconflow.cn 结构（Hero + 产品矩阵 + 为什么选择深色数据带 + 行业方案 Tab + 合作伙伴 + CTA），文案适配本 Token 聚合分发平台，保留了原 moyu-landing 的三个模型套餐（豆包视频 2.0 / MiniMax m2.7 / Z-image）。
- 关键机制（重要）：首页内容经 `web/src/pages/Home/index.jsx` 的 `dangerouslySetInnerHTML` 注入，**`<script>` 不会执行**——页面交互必须纯 CSS 实现（keyframes / radio `:checked` / hover）。全部类名需带 `sf-` 前缀避免污染宿主 Semi UI 样式。
- 纯 CSS 轨道动画要点：卫星元素 transform 必须 `rotate(a) translateX(r) rotate(-a)`（最后的反向旋转让内容归正），芯片再用反向 keyframes 抵消公转，文字才能始终水平。
- 启用方式：/console/setting?tab=other → 首页内容设置，填完整 URL `http(s)://<域名>/silicon-landing.html`；生产环境需 `bun run build` 让文件进入 dist。
- 已用 Playwright 截图验证桌面/移动渲染、Tab 切换、无横向溢出。
