New API（词链API）是新一代AI模型扩展网关与AI资产管理系统， 支持OpenAI、Claude、Gemini等主流AI模型的统一接入与管理， 通过智能化的资源调度和优化算法，为企业提供稳定、高效、安全的API服务。

关于词链 API

New API（词链API）是一款功能强大的AI模型网关与资产管理系统， 致力于为全球开发者和企业提供统一、高效、安全的AI模型接入解决方案。

平台支持多种主流AI模型和API格式，包括OpenAI Responses、OpenAI Realtime API、 Claude Messages、Google Gemini等，涵盖文本生成、图像创作、语音识别、视频生成等多个领域。 通过智能化的资源调度和优化算法，为用户提供极致的使用体验。

项目名称 New API（词链API）
项目定位 AI模型扩展网关
核心技术 智能资源调度与优化
服务类型 SaaS / API 服务
